# BDSクロバス

関西大学ビジネスデータサイエンス学部の学生による、学生のための情報共有アプリです。

## できること
- **授業を探す**: 公式シラバス（2026年度・BDS学部専門教育科目 全135クラス / 59科目）から、成績評価の割合（定期テスト・レポート・出席など）で絞り込み・並び替え
- **口コミ**: 授業ごと・先生ごとに口コミを投稿（取りやすさ／充実度／課題の重さ）
- **過去問**: 過去問・過去課題の情報（年度・形式・出題傾向）を共有
- **ゼミ一覧**: 担当教員16ゼミの研究分野・タグ・書き込み。説明会日程とオンデマンドURLは学生が追加できる
- **カレンダー**: テスト日・締切・ゼミ説明会をみんなで登録
- **教科書売買**: 使い終わった教科書の出品・検索
- **掲示板**: 学部内の情報共有
- **学生限定登録**: 学籍番号（k+数字6桁）の形式チェックで登録。教員・学外者は登録できない設計

## データについて
授業データは関西大学公式シラバスから取得した公開情報です。口コミ等の投稿はブラウザのlocalStorageに保存されるMVP構成で、端末をまたいだ共有（バックエンド化）は今後の課題です。

## 技術
静的サイト（HTML/CSS/JavaScript）。ビルド不要。
